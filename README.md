# Turisur Backend

API y servicios en tiempo real para la aplicación móvil y el panel
administrativo de Buses Turisur.

Repositorio de solo lectura con fines de referencia técnica. Las
credenciales y variables de entorno no están incluidas.

## Módulos

- Autenticación con Supabase Auth
- Telemetría GPS en tiempo real vía Socket.io
- Gestión de tickets y validación por QR
- Pagos Webpay Plus
- Almacenamiento en Google Cloud Storage
- Jobs programados

## Stack

Node.js · Express · Socket.io · Supabase · Google Cloud Storage · Webpay Plus · EJS
